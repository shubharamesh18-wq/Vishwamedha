# Legacy

Archived earlier version of the site (`vcsconsult`), kept for reference only.
It is a static HTML + Node server build and is **not** part of the Next.js app.

- `vcsconsult/server.js`, `storage.js`, `db/schema.sql`: booking backend, useful reference for Phase 2
- `vcsconsult/public/`: original static pages and assets

This folder is excluded from the TypeScript build. Do not import from it.
